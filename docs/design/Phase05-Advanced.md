## 拆分理由

原 Phase05 在一个阶段内包含三大块互不相关的高复杂度工作：

| 模块 | 评估工作量 | 技术挑战 |
|------|-----------|---------|
| WYSIWYG 即时渲染 | ~8-10 天 | 最大：CM6 Decoration 插件、SyntaxMarker 分析器、光标感知算法 |
| 专注/打字机模式 | ~1-2 天 | 中等：CSS 行置灰、滚动居中 |
| 性能优化 + Bug 修复 | ~3-4 天 | 分散：morphdom、DOMPurify、大文件处理、10+ 个 Bug |

WYSIWYG 是 Phase05 的核心价值、也是技术难度最高的模块，将其独立成一个完整阶段可：
1. 保证有充足时间精细实现和测试 Decoration 插件
2. 专注模式 / Bug 修复不依赖 WYSIWYG，可独立串行推进
3. 如有延期风险，WYSIWYG 完成后即可交付 Phase05-1 的可用版本

## 依赖关系

```
Phase05-1 (WYSIWYG)        Phase05-2 (专注/性能/Bug修复)
      │                            │
      │  无依赖关系 ◄──────────────┤
      │                            │
      ▼                            ▼
  可并行推进                    可并行推进
```

两者**不互相依赖**，可以按任意顺序实施。
