开发自己的本地版 Typora，这是一个系统性的工程。其核心挑战在于实现**所见即所得的“即时渲染”**：既要实时看到排版效果，又要能随时像“修改源码”一样编辑语法，这需要在文档模型上做精细设计。


### 🧐 功能调研与竞品分析

深入了解 Typora 及相关竞品的功能，是明确自己开发需求的第一步。

#### Typora 核心功能

| 功能分类 | 具体特性 | 说明 |
| :--- | :--- | :--- |
| **编辑体验** | 即时渲染 (Live Preview) | 这是 Typora 的灵魂所在。语法键入完即渲染，隐藏标记符，让界面如富文本编辑器般简洁。 |
| | 专注模式/打字机模式 | 当前段落高亮，其余内容置灰或隐藏，帮助提升写作专注力。 |
| | 快捷键系统 | 支持丰富的快捷键，并允许用户自定义。 |
| **文档管理** | 文件夹/文件树侧边栏 | 在侧边栏以树形结构展示打开的文件夹内所有文件。 |
| | 大纲面板 | 根据文档标题自动生成大纲，支持快速导航。 |
| | 全局搜索 | 支持在当前打开的文件夹内进行全文搜索，并支持模糊匹配。 |
| | 快速打开 (Quick Open) | 通过快捷键 (Ctrl/O) 唤起面板，模糊搜索并快速打开文件。 |
| **文档内容** | 标准 Markdown 语法 | 全面支持 CommonMark 和 GitHub Flavored Markdown (GFM) 规范。 |
| | 表格支持 | 支持可视化编辑表格，能轻松创建和调整行列。 |
| | 代码块 | 支持超过 64 种语言的语法高亮、行号显示等。 |
| | 数学公式 | 原生支持 LaTeX 语法的数学公式渲染。 |
| | 图表 | 支持使用 Mermaid、PlantUML 等工具描述并生成图表。 |
| | 图片处理 | 支持拖拽、粘贴插入图片，并可实现图床自动上传。 |
| **导出与集成** | 多格式导出 | 可将文档导出为 PDF、HTML、Word (通过 Pandoc) 等多种格式。 |
| | 版本控制友好 | 兼容 Git，可将 Typora 配置为 Git 的默认合并工具，方便进行版本管理。 |
| **个性化** | 主题系统 | 通过修改 CSS 文件来完全更换编辑器的外观样式。 |

#### 其他优秀编辑器参考

*   **开源替代品**：如 **MarkText** (GitHub 22.8k stars) 和 **Haptic**，它们的目标就是复刻 Typora 的体验，代码是绝佳的学习范本。
*   **扩展性参考**：**Obsidian** 和 **Vditor** 的插件系统、**Cherry Markdown** 的企业级协同和扩展能力，代表更高级的方向。

这些分析揭示了“即时渲染”是技术难点，但也是项目最有价值的部分。
